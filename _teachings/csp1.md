#### What we did in class

* **01.10.2025:** We introduced the notion of relational structure. For a relational structure $$\mathbb{A}$$, we defined the constraint satisfaction problem $$\text{CSP}(\mathbb{A})$$ and found polynomial-time algorithms for some special cases. [[Sheet 1](https://hadekm.github.io/docs/CSPseminar_exercises.pdf), Problem 1]
* **08.10.2025:** *Plan:* finish the first exercise sheet. Equivalent definition of $$\text{CSP}(\mathbb{A})$$ using homomorphisms of relational structures.
